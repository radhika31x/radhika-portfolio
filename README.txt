YOUR PERSONAL PORTFOLIO WEBSITE

HOW TO OPEN
1. Extract the ZIP file.
2. Open the portfolio_website folder.
3. Double-click index.html to view the website in your browser.

CUSTOMIZE BEFORE SUBMISSION
- In index.html, Radhika Sharma details are already added.
- Update the About Me text, skills and sample projects with your real details.
- Add your email address, GitHub URL and other social links before submitting. LinkedIn is already linked.
- The Hackathon Winner section is included; edit its text with your event/team details.
- You can change the browser tab title in the <title> tag.

FILES
- index.html: website content
- style.css: design, layout, responsive styling and animations
- script.js: mobile navigation and scroll reveal animations

The website is responsive and uses HTML, CSS and vanilla JavaScript.
Google Fonts are loaded online; the page still works with fallback fonts if offline.
